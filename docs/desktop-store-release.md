# Desktop Store Release Plan

This document tracks what still needs to happen before SentinelStream Analyst
Desktop can be submitted to Microsoft Store.

## Current status

The app has:

- Windows installer and portable EXE outputs
- desktop settings persistence
- external and embedded launch modes
- Store listing draft copy
- privacy-policy and support-page drafts

The app does not yet have:

- a finalized end-user runtime model
- public production URLs for privacy and support
- production icon and screenshot assets
- a signed installer and hosted release URL
- a completed Partner Center submission

## Minimum path to Microsoft Store

1. Finalize the public runtime model
2. Replace placeholder contact and legal details
3. Publish these pages publicly:
   - `docs/legal/privacy-policy.md`
   - `docs/legal/support.md`
4. Capture Store screenshots
5. Create or import final branding assets
6. Sign the installer
7. Host the versioned installer on HTTPS
8. Reserve the app name in Partner Center
9. Submit the listing and binaries

## Suggested public positioning

Product name:

- `SentinelStream Analyst Desktop`

Category:

- `Business`

Positioning:

- analyst workstation for fraud-monitoring and decision-review workflows
- cybersecurity-relevant risk investigation client
- pilot-ready desktop shell for connected SentinelStream environments

## Current release recommendation

Public website or controlled beta: reasonable

Microsoft Store public sale: not ready yet
