## Common issues

### The app cannot reach the analyst console

Check:

- the configured target URL
- whether the backend is running
- whether firewall or proxy settings are blocking access

### Embedded mode does not start

Check:

- Python executable path
- repository root setting
- backend working directory
- local dependency installation

### I want to switch environments

Open the in-app Settings screen and update:

- connection mode
- target URL
- port
- embedded-mode paths if needed
