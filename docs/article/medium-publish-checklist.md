# Medium Publish Checklist

Use this checklist for publishing the SentinelStream milestone article on Medium.

## Current preview URL

Temporary public article URL:

```text
https://great-spoons-tap.loca.lt/article/
```

Medium import URL:

```text
https://medium.com/p/import?url=https%3A%2F%2Fgreat-spoons-tap.loca.lt%2Farticle%2F
```

Note: the `loca.lt` URL is temporary. For a permanent canonical URL, publish the
`docs/` site through GitHub Pages and use the GitHub Pages article URL.

## Recommended title

I Built a Cloud-Native Fraud Detection Platform, Then Rebuilt the Path to the
Product When the Cloud Failed Me

## Recommended subtitle

How SentinelStream grew from a systems design challenge into a working analyst
platform, a local fallback path, and a Windows desktop milestone.

## Suggested tags

- Software Engineering
- Cybersecurity
- Fraud Detection
- Microservices
- Kubernetes

Medium allows up to five tags at publish time.

## Final publish steps

1. Open the Medium import URL above.
2. Confirm the article imports cleanly.
3. Review headings, spacing, and code formatting.
4. Add screenshots or diagrams if available.
5. Open publish settings.
6. Add the five tags above.
7. If Medium allows canonical customization, use the permanent GitHub Pages URL
   once the site is live there.
8. Publish.

## Visuals to add before publishing

- architecture diagram after the architecture section
- service health or Kubernetes screenshot after the debugging section
- analyst console screenshot after the desktop app section
- desktop installer or app screenshot near the conclusion
