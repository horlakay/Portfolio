Release Planning

Desktop Store release plan

The SentinelStream Analyst Desktop app now has a working shell, Windows build artifacts, and Store-preparation materials. This page tracks the remaining steps before Microsoft Store submission.

Read the milestone article Open markdown source

Current status

Good enough for a public engineering milestone archive and controlled release preparation. Not yet ready for full Microsoft Store submission.

What is already done

  • Windows installer and portable EXE outputs exist
  • The desktop app supports external and embedded launch modes
  • Desktop settings persistence is implemented
  • Store listing draft copy exists
  • Privacy-policy and support-page drafts exist

What still needs to happen

  1. Finalize the public runtime model
  2. Replace placeholder legal and contact details
  3. Publish privacy and support pages at stable public HTTPS URLs
  4. Create production logo assets and Store screenshots
  5. Sign the installer
  6. Host the versioned installer on HTTPS
  7. Reserve the product name in Partner Center
  8. Submit the listing and binaries

Current recommendation

SentinelStream Analyst Desktop is appropriate for a public project website, technical article, and controlled beta distribution. It is not yet honest to describe it as Microsoft Store-ready for sale until the release pipeline, public metadata, and legal/support surfaces are finalized.

Suggested positioning

  • Analyst workstation for fraud-monitoring workflows
  • Cybersecurity-relevant risk investigation client
  • Product shell for connected SentinelStream environments
